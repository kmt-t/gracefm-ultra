# PostNet の設計

**PostNet** は、MendNet の出力（帯域係数の事後平均 `e0` と事後標準偏差 `sd`）から、量子化の雑音の床に沈んだ弱い高域（ピアノの倍音など）を復元する超解像の網です。元の音質が良いときだけ適用します。

## なぜ MDCT か

ピアノなどの高域（4 kHz 以上）は原音で `−60〜−100 dB/bin` と弱く、MendNet 出力の量子化雑音に埋もれやすい。時間領域や帯域分割領域の二乗誤差は全帯域を同じ重みで扱うため、弱い高域が損失に現れにくい。MDCT にして帯域ごとに分け、各帯域を原音エネルギーで正規化することで、弱い高域も同等の重みで学習させる。

## 変換と雑音の地図

- **MDCT**: 窓長 512、ホップ `M = 256`（32 kHz で 8 ms）、サイン窓、直交（TDAC で完全再構成）。`Conv1d` / `ConvTranspose1d` で実装（`postnet.Transform`）。
- **帯域合成**: 帯域ごとの基底の畳み込み（`transform.basis`）。LeGall 5/3 は係数が隣フレームの標本にも届くため、前後 1 フレーム（`REACH`）を入力に足す（Haar も同じ手順に統一）。
- **雑音の地図**: 係数誤差を互いに独立とみなし、分散を線形変換の二乗で移す（係数 → 波形 → MDCT）。
- **成分**: M・S ごとに同じ重みで処理する。

## ネットワーク構成

MDCT フレーム列に対する TCN（`postnet.PostNet`）。

- **入力**: `asinh(X / 10⁻⁴) / 8`（256）、`log10(雑音の分散) / 8 + 1`（256）、成分（1）。
- **本体**: 10 段の残差ブロック（256 ch、飛び幅 `1, 1, 2, 4, 8, 1, 2, 4, 8, 16`）。正規化はフレームごと（チャンネル方向のみ。時間方向の統計を使わないため因果かつ長さ非依存）。
- **受容野**: 先読みは最初の 2 段（各 1 フレーム）のみで残りは因果。因果の段が見る過去は 92 フレーム（32 kHz で 736 ms）。
- **出力**: 各ビンのゲイン `g` と加算量 `a` を出し、`Y = 2σ(g)·X + 2·tanh(a)·√(雑音の分散)`。加算量は事後標準偏差の 2 倍までに制限（1 フレームの暴走防止）。初期値は恒等写像（`Y = X`）。

## 判定（超解像をかけるか）

MendNet の事後標準偏差から出す予測 SNR で判定する。

$$\text{予測 SNR} = \frac{\sum w \, e_0^2}{\sum w \, \text{sd}^2}$$

（過去 500 フレーム＝32 kHz で 1 秒間の、係数が使えたフレームで集計。`w` は基底エネルギー）

- **閾値とヒステリシス**: `27.5 dB` 以上でオン、オン中は `25.5 dB` を下回るまでオン（閾値付近の頻繁な切り替わりで音がばたつくのを防ぐ）。ターゲットは B200 で Es/N0 18 dB（C/N0 70.4 dB-Hz）付近。
- **起動直後**: 過去 500 フレームが揃うまで（先頭 1 秒間）はオフ。
- **追従精度**: 実際の係数 SNR に 1.3 dB 以内で追従する（B200-L AWGN、下表参照）。
- **切り替え単位**: 判定自体はフレームごとに行い、MDCT フレームは「窓がかかる 8 フレームがすべてオン」のときだけ超解像を適用する（オフ時は MendNet 出力のまま）。窓の重なり（32 kHz で 8 ms）により滑らかにつながる。

## 学習

- **データ**（`tools/gen_post.py`）: 確定した MendNet で学習データの各区間・シナリオを丸ごと復元した `e0`, `sd` と原音。シナリオは半分が Es/N0 `0〜16 dB`、半分が `16〜40 dB`、フェージング 50%、欠落 50%。
- **切り出し**（`tools/train_post.py`）: MDCT 192 フレーム。損失対象（先頭 96 MDCT フレームより後）がすべて判定オンの区間を選ぶ（先頭文脈はオフでも可とし、オフ→オンの遷移も学習させる）。
- **損失**（`postnet.post_loss`）:
  - `フレーム・帯域（臨界帯域に近い 24 本）ごとの log(誤差 / (原音 + 10⁻¹⁰·ビン数) + 10⁻⁶) の平均 + 0.1 × 複数解像度 (256, 512, 1024) の対数振幅 L1`
  - `ε = 10⁻⁶`（`−60 dB`）はコーデック SNR 上限（50 dB 強）より下にするため（`log(1 + 相対誤差)` では小誤差で勾配が消え、SNR 25 dB 前後で頭打ちになった）。

## 受信での実行

- **ONNX グラフ**（`tools/export_onnx.py` → `engine/models/<プロファイル>/postnet.onnx`）: 1 歩分のグラフ。`係数 → 波形 → MDCT → PostNet → 切り替え → 逆 MDCT` をすべて含む。
- **状態管理**（`engine/gfm-core/src/post.rs`）: 段ごとの過去入力（先読み段は 1 フレーム、因果段は `2 × 飛び幅`）を状態として持ち越す。確定フレームのみで決まる位置まで状態を進め、暫定フレームに頼る部分は毎回計算し直す。
- **一致検証**: 逐次処理は全体一括処理と一致する（`tools/export_onnx.py` で差を確認）。
