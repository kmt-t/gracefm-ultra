# PostNet の設計

PostNet は、MendNet の出力（帯域係数の事後平均 e0 と事後標準偏差 sd）から、量子化の雑音の床に沈んだ弱い高域（ピアノの倍音など）を復元する超解像の網。
元の音質が良いときだけかける。

## なぜ MDCT か

ピアノなどの高域（4 kHz 以上）は、原音で −60〜−100 dB/bin と弱く、MendNet の出力の誤差（量子化の雑音）に埋もれやすい。
時間領域や帯域分割の領域の二乗誤差は、どの帯域の誤差も同じ重みで数えるので、弱い高域は損失にほとんど現れない。MDCT にして帯域ごとに扱い、帯域ごとに原音のエネルギーで正規化して、弱い帯域も同じ重みで学ぶ。

## 変換

- MDCT: 窓長 512、ホップ M = 256（32 kHz で 8 ms）、サイン窓、直交（TDAC で完全再構成）。Conv1d / ConvTranspose1d で組む（`postnet.Transform`）。
- 合成: 帯域ごとの基底の畳み込み（`transform.basis`）。LeGall 5/3 のフレームの係数は隣のフレームの標本にも届くので、前後 1 フレーム（`REACH`）の係数も入力に足す。Haar は届かないが、受信の手順はそろえて同じ形にする。
- 雑音の地図: 係数の誤差を互いに独立とみなし、分散を線形変換の二乗で移す（係数 → 波形 → MDCT）。
- 成分（M、S）ごとに同じ重みで走らせる。

## 網

MDCT のフレーム列の TCN（`postnet.PostNet`）。

- 入力: asinh(X / 10⁻⁴) / 8（256）、log10(雑音の分散) / 8 + 1（256）、成分（1）。
- 10 段の残差ブロック（256 チャンネル、飛び幅 1, 1, 2, 4, 8, 1, 2, 4, 8, 16）。正規化はフレームごと（チャンネル方向。時間方向の統計を使わないので、因果で長さによらない）。
- 先読みは最初の 2 段（各 1 フレーム）だけで、残りは因果。因果の段が見る過去は 92 フレーム（32 kHz で 736 ms）。
- 出力: 各ビンのゲイン g と足し込む量 a。Y = 2σ(g)·X + 2·tanh(a)·√(雑音の分散)。足し込みは事後標準偏差の 2 倍まで（1 フレームの暴走を防ぐ）。初期値は恒等（Y = X）。

## 判定（超解像をかけるか）

MendNet の事後標準偏差から出す予測の SNR = Σ w e0² / Σ w sd²（過去 500 フレーム（32 kHz で 1 秒）の、係数が使えたフレーム。w は基底のエネルギー）。

- 27.5 dB 以上でオン、オンの間は 25.5 dB を下回るまでオン（ヒステリシス）。ターゲットは B200 で Es/N0 18 dB（C/N0 70.4 dB-Hz）あたりから。
- 過去が 500 フレーム（32 kHz で 1 秒）揃うまではオフ。
- 予測の SNR は、実際の係数の SNR に 1.3 dB 以内の差で追従する（B200-L の AWGN、下の表）。
- 判定はフレームごと。MDCT のフレームは、窓がかかる 8 フレームが全部オンのときだけ超解像し、オフのフレームは MendNet の出力のまま。切り替えは MDCT のフレームごとで、窓の重なり（32 kHz で 8 ms）でつながる。
- ヒステリシスがないと、閾値の前後で切り替わりが増え、復元できたフレームとできないフレームが交互に聞こえる。

## 学習

- データ（`tools/gen_post.py`）: 確定した MendNet で、MendNet の学習データの各区間・各シナリオを丸ごと復元した e0、sd と原音。シナリオは半分が Es/N0 0〜16 dB、半分が 16〜40 dB、フェージング 50%、欠落 50%。
- 切り出し（`tools/train_post.py`）: MDCT 192 フレーム。損失に入るフレーム（先頭 96 MDCT フレームより後）で判定が全部オンのところだけ。先頭の文脈は判定がオフでもよい（オフからオンに入る切り替わり目も学ぶ）。
- 損失（`postnet.post_loss`）: フレーム・帯域（臨界帯域に近い 24 本）ごとの log(誤差 / (原音 + 10⁻¹⁰·ビン数) + 10⁻⁶) の平均 + 0.1 × 複数解像度（256、512、1024）の対数振幅の L1。
  ε = 10⁻⁶（−60 dB）は、コーデックの SNR の上限（50 dB 強）より下にする。log(1 + 相対誤差) では、小さい相対誤差で勾配がなくなり、SNR が 25 dB 前後で頭打ちになった。

## 受信での実行

- ONNX（`tools/export_onnx.py` → `engine/models/<プロファイル>/postnet.onnx`）は 1 歩ぶんのグラフ。係数 → 波形 → MDCT、PostNet、切り替え、逆 MDCT までを入れる。
- 段ごとの入力の過去（先読みの段は 1 フレーム、因果の段は 2 × 飛び幅）を状態として持ち越す（`engine/gfm-core/src/post.rs`）。確定したフレームだけで決まる位置まで状態を進め、暫定のフレームに頼る部分は毎回計算し直す。
- 逐次処理は、全体を一度に通したものと一致する（`tools/export_onnx.py` が差を出す）。
