# MendNet の設計

MendNet は、使えないフレーム（欠落・基本 CRC 不一致）の音を、前後の文脈と、副系（SUB）があれば副系、壊れたフレームに残る手がかりから、補う DNN。
ビット誤りを救済する HaarNet とは別のモデルで、CRC が通ったかどうかで担当が分かれる。

## 担当

| フレームの状態 | 担当 | 入力 |
|---|---|---|
| 基本 CRC が通る | HaarNet（ビット誤りの救済） | 受信 LLR、刻み（ヘッダ）、E0 |
| 基本 CRC が通らない、届かない | MendNet | 前後の文脈、副系、壊れたフレームの尺度なしの手がかり |

CRC が通らないフレームを増やさないために、MendNet の前に、**ヘッダを事前知識つきで復号する段（段 A）** を置く。

## 段 A: ヘッダの事前知識つき復号（DNN ではない）

ヘッダの情報ビットは予測できる。予測を、ビタビ復号の情報ビット側の軟値に事前分布として足し、基本 CRC を通る確率を上げる。

| ヘッダの項目 | 予測の源 |
|---|---|
| プロファイル ID、系統 ID、形式識別子、暗号化ビット | 既知（確定値） |
| フレーム番号（16 bit） | 直前のフレーム番号 + 1（欠落があれば、届いた位置から数える） |
| 指数（k = 0〜2、M/S） | **副系がある**: 副系で復号した同じブロックの係数のピーク。副系なし: 前後のフレームの指数 |
| アッテネータ（k = 0〜2） | 事前確率（学習データの頻度） |
| 保護された仮数の上位 K bit（k = 0〜2） | 副系の係数と予測した指数から、符号と最上位 bit を予測 |

基本 CRC に入る指数は k < high_k（= 3）の帯域、つまり k = 0〜2 だけ。**副系（SUB100 など）が持つ帯域は k = 0〜2** なので、基本 CRC の内容は、副系から予測できる範囲とぴったり重なる。

指数の予測: 帯域 k の副系の復号係数のピーク |c|max から、主系の指数 e = ceil(log2(|c|max / qmax_主)) を求め、{e−1, e, e+1} に事前確率を置く（主系がクリップ最適化で 1 つ小さい指数を選ぶことと、副系の量子化誤差のため）。指数 4 bit の各ビットの事前 LLR は、この 3 候補の分布から作る。

副系の対応（DEFAULT_SUB）と、副系が持つ帯域:

| 主系 | 副系 | 副系の M 帯域 | 副系の S 帯域 | 主系の基本 CRC の指数のうち、副系で予測できるもの |
|---|---|---|---|---|
| B200 | SUB100 | k = 0, 1, 2 | k = 0, 1, 2 | すべて |
| B200M | SUB50M | k = 0, 1, 2 | なし（M のみ） | すべて |
| M700 | SUB100-48K | k = 0, 1, 2 | k = 0, 1 | S の k = 2 だけ予測できない（前後の指数で補う） |
| M700M | SUB100-48K | k = 0, 1, 2 | k = 0, 1（主系に S なし） | すべて |

段 A の効果の測定（B200、基本 CRC 不一致の割合 [%]。`tools/eval_header_prior.py`、`engine/gfm-core/examples/prior_bound.rs`）:

| 通信路 | なし | フレーム番号 + 直前の指数 | + 副系の指数 | 上限: 予測できる項目を正解で | 上限: ヘッダ全体を正解で | 上限: ヘッダ + 保護ビットを正解で |
|---|---|---|---|---|---|---|
| AWGN 5 dB | 79.0 | 47.8 | 43.3 | — | — | — |
| AWGN 6 dB | 46.4 | 21.4 | 19.0 | 16.5 | 0.0 | 0.0 |
| AWGN 7 dB | 16.4 | 7.7 | 7.1 | — | — | — |
| AWGN 8 dB | 3.0 | 1.1 | 1.1 | 0.5 | 0.0 | 0.0 |
| Rayleigh 6 dB | 70.6 | 63.5 | 61.2 | 59.7 | 27.5 | 1.3 |
| Rayleigh 8 dB | 53.2 | 45.4 | 43.4 | 41.9 | 16.6 | 0.9 |

- AWGN: 実際の予測（フレーム番号 + 指数）は、予測できる項目を正解で与えた上限（16.5%、6 dB）にほぼ届く。残りの不一致は、予測できないアッテネータと CRC のビット（合わせて 22 bit 程度）による。ヘッダ全体が分かれば、不一致はほぼ 0 になる。保護ビットは AWGN では支配的でない。
- Rayleigh: 深いフェージングでフレーム全体が壊れるため、ヘッダを正解で与えても 16〜28% が残る。保護ビットも分かれば約 1%。保護ビットの予測（副系の係数から符号と最上位ビット）が効くのは、こちら。
- 副系の指数予測の上積みは、AWGN で 2〜5 ポイント、Rayleigh で 1〜2 ポイント。

次の手段: CRC は線形なので、フレーム番号と指数を固定し、未知のアッテネータ（M/S の k = 2 の 4 + 4 bit）の候補ごとに CRC のビットが決まる。候補（最大 256 通り）を符号化して受信の軟値と照合し、最も合うものを採る（CRC 制約つきの最尤復号）。上限（ヘッダ全体が正解）に近づける。

## MendNet の入出力（共通）

- 窓: 100 フレーム（200 ms @ 32 kHz）、非因果、固定長。成分（M、S）ごとに同じ網を共有し、成分をバッチ軸に並べる（M だけのプロファイルは M のみ）。
- 係数ごとの入力（64 係数 × 2 チャンネル）:
  - 値の手がかり: 使えるフレームは復号した係数、壊れたフレームは**尺度なしの手がかり**（仮数の推定値 / qmax。指数が不明でも、帯域内の相対的な形は残る）、欠落は 0。帯域ごとの文脈の rms で規格化する。
  - 信頼度: log2(誤差分散)（情報なしは固定の大きな値）。
- フレームごとの入力: 状態の one-hot（正常、壊れた、欠落）、指数が確定したか。
- 出力: 使えないフレームの 64 係数（規格化を戻す）。出力段の両端クロスフェードと、欠落区間だけの IIR 切替は、そのまま使う。
- 演算は ONNX に出せるもの（Conv1d、GELU、GroupNorm）だけ。入力の形は固定。

## 副系あり / なし: 網を分ける

プロファイルの組（主系 + 副系）は起動時に分かるので、モデルは別々にして、実行時に選ぶ。

| | 副系なし（MendNet） | 副系あり（MendNet-S） |
|---|---|---|
| 追加の入力 | なし | 副系の係数（k = 0〜2、M/S）の値と信頼度、副系の状態（同じフレーム格子） |
| 主系が使えないフレームの仕事 | 全帯域を前後の文脈から補う | 副系があれば k = 0〜2 は副系から。**高域（k = 3、4）を、副系の低域と文脈から作る（帯域拡張）** |
| 主系・副系とも使えないフレーム | 同じ | 文脈から補う（副系なしと同じ難しさ） |
| 学習の通信路 | 主系の損失・CRC 不一致 | 主系と副系で独立な損失・フェージング |
| 容量 | 既存の MendNet と同程度（192 チャンネル、12 ブロック） | 入力の幹を増やす。本体は同程度。高域の生成のため、k = 3、4 の出力に専用の頭を足す |

副系あり・主系だけ使えない状況が、最も多い。ここで高域をどれだけ自然に作れるかが、聴感の勝負になる。

## 学習データ

- gfm-gen を拡張して、主系・副系を同じ音源で符号化し、独立した通信路を通す。実際の Decoder を走らせて、フレームの状態、復号した係数と誤差分散、壊れたフレームの尺度なしの手がかりを書き出す。
- 状態の分布は、実際の復号の結果（段 A を含む）から作る。人工の欠落パターンだけにしない。
- 音源は、HaarNet の学習データと同じ分割（train / val は音源の番号で分ける）。

## 損失と評価

- 損失: 使えないフレームの係数の、帯域ごとの相対二乗誤差。両端 8 フレームの連続性の項を足す。漏れを直接抑える項は入れない（出力段のクロスフェードと IIR 切替に任せる）。
- 評価は聴感を優先する。数値は、欠落区間の SNR を、LPC・AR 補間と比べる。高域の生成は、スペクトログラムと聴き比べで確かめる。副系あり・なし、主系の損失率ごと。

## 未決事項

1. 壊れたフレームの尺度なしの手がかりが、補間をどれだけ良くするか（測定してから決める）。
2. 副系あり・なしで本当に網を分ける価値があるか。同じ網に副系の入力をゼロで渡す案との比較。
3. 段 A の事前知識を入れたときの、誤ったヘッダの採用（CRC の誤採用）の増え方。
4. ステレオ（S 成分）を M と同じ網で扱ってよいか。
5. 実時間の計算量（ONNX Runtime、CPU）。
