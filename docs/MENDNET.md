# MendNet の設計

**MendNet** は、前後の文脈・受信 LLR・壊れたフレームに残る手がかりから、全フレームの仮数ビットの LLR とヘッダ復号不可フレームの刻みを出力する DNN です（受信は 1 系統）。

- **使えるフレーム**（基本 CRC 一致）: 受信 LLR を補正する。
- **使えないフレーム**（欠落・基本 CRC 不一致）: 係数と刻みを補間する。
- **出力係数**: 出力 LLR から求めた仮数の期待値 × 刻み（事後平均 `E0`）と、その事後標準偏差（怪しさ）。
- **外れ値抑制**（`mendnet.limit_e0`）:
  - 欠落フレームの係数・標準偏差: 窓内の使えるフレームにおける同じ係数の最大値までに制限（32 kHz で 200 ms 超の全欠落窓では手がかりがないため上限 0 となり無音）。
  - その他のフレームの係数: `±2`（満点 1）までに制限。

## 処理の分担

| フレームの状態 | 担当 | 入力 |
|---|---|---|
| 基本 CRC が通る | MendNet（受信 LLR の補正） | 受信 LLR、刻み（ヘッダ）、前後の文脈 |
| 基本 CRC が通らない・届かない | MendNet（補間） | 前後の文脈、受信 LLR、壊れたフレームの尺度なしの手がかり |

CRC 通過率を上げるため、MendNet の前段に **ヘッダを事前知識つきで復号する段（段 A）** と **リスト復号（段 A'）** を置く。

## 段 A: ヘッダの事前知識つき復号（非 DNN）

ヘッダの情報ビットの多くは予測できるため、ビタビ復号の情報ビット側の軟値に事前分布として加算し、基本 CRC の通過率を高める（実装: `engine/gfm-core/src/prior.rs`）。

| ヘッダ項目 | 予測の源 |
|---|---|
| プロファイル ID・形式識別子・暗号化ビット | 既知（確定値） |
| フレーム番号（16 bit） | 直前に復号できたフレームの番号 + 経過フレーム数 |
| 指数（M/S の各帯域） | 直前に復号できたフレームの指数（近いほど確か） |
| アッテネータ・CRC | 予測しない |

### 段 A の効果測定

基本 CRC 不一致率 `[%]`（実験時の直交 Haar で B200 を符号化した値。S 変換では指数の統計が少し変わるため目安）:

| 通信路 | なし | 事前知識あり | 上限: 予測項目を正解 | 上限: ヘッダ全体を正解 | 上限: ヘッダ + 保護ビットを正解 |
|---|---|---|---|---|---|
| AWGN 5 dB | 79.0 | 47.8 | — | — | — |
| AWGN 6 dB | 46.4 | 21.4 | 16.5 | 0.0 | 0.0 |
| AWGN 7 dB | 16.4 | 7.7 | — | — | — |
| AWGN 8 dB | 3.0 | 1.1 | 0.5 | 0.0 | 0.0 |
| Rayleigh 6 dB | 70.6 | 63.5 | 59.7 | 27.5 | 1.3 |
| Rayleigh 8 dB | 53.2 | 45.4 | 41.9 | 16.6 | 0.9 |

- **AWGN**: 事前知識により予測項目を正解で与えた上限（6 dB で 16.5%）に近づく。残りは予測できないアッテネータと CRC（計 22 bit 程度）によるもので、ヘッダ全体が分かれば不一致はほぼ 0。
- **Rayleigh**: 深いフェージングでフレーム全体が壊れるため、ヘッダが正解でも 16〜28% が残る（保護ビットも分かれば約 1%）。

### 段 A': CRC 付きリスト復号

最尤（ビタビ）で基本 CRC が通らない場合、ヘッダを尤度順の候補（リストビタビ）から探索し、最初に基本 CRC が合うものを採用する（実装: `framing::unpack` の `list`、既定 `8`）。

- **注意点**: CRC は 12 bit のため、1 候補あたり `2^-12` の確率で誤った候補が偶然通過する。リストが深いほど・通信路情報が薄いほど誤採用が増える。
- **残す情報**: 採用した候補の順位（`rank`）と最尤との対数尤度差（`gap`）を `Unpacked` に残し、MendNet の信頼度入力に使う。

測定（上と同条件、1000 フレーム、事前知識あり）。形式は `基本 CRC 不一致 fail [%] / 誤採用 wrong [%]`（採用したがフレーム番号または基本 CRC 保護対象の指数・アッテネータが真値と異なる割合）:

| 通信路 | L1 | L4 | **L8** | L16 | L32 |
|---|---|---|---|---|---|
| AWGN 4 dB | 78.5 / 0 | 61.0 / 0 | 53.8 / 0 | 44.5 / 0 | 36.8 / 0.1 |
| AWGN 5 dB | 48.5 / 0 | 27.2 / 0 | 20.5 / 0 | 15.7 / 0 | 11.5 / 0 |
| AWGN 6 dB | 21.7 / 0 | 6.5 / 0 | 4.4 / 0 | 2.3 / 0 | 1.3 / 0 |
| Rayleigh 4 dB | 80.2 / 0 | 75.5 / 0 | 73.8 / 0 | 71.9 / 0.2 | 70.5 / 0.5 |
| Rayleigh 6 dB | 64.2 / 0.1 | 58.3 / 0.1 | 56.2 / 0.1 | 54.2 / 0.2 | 52.3 / 0.4 |
| Rayleigh 8 dB | 46.1 / 0 | 39.9 / 0 | 37.7 / 0.2 | 35.1 / 0.3 | 33.2 / 0.3 |

- **効果**: 事前知識なしの通常復号（L1）は AWGN 5 dB で 78.4%、6 dB で 46.0%。事前知識 + リスト 8 で **20.5% / 4.4%** まで下がり、誤採用は AWGN で 0、Rayleigh で最大 0.2% に留まる。
- **不採用とした手法**: `gap` による足切り、通信路のヘッダ支持強度（`evidence`）による足切り（誤採用フレームも正常フレームと同範囲の値を持つ）、プリアンブルからの雑音分散校正（AWGN で不一致が増え、誤採用も減らない）。

## MendNet の入出力

### 入力単位と形状

- **窓**: 成分（M または S）1 つ × `T = 100` フレーム（非因果。32 kHz で 200 ms、48 kHz で 133 ms）。
- **バッチ配置**: M と S は別の標本としてバッチ軸に並べ、重みを共有する（モノラル等の S がないプロファイルは M のみ）。
- **プロファイル非依存の形状**: 送らない帯域・成分の係数は `0` 埋めし、入力形状 `(B, C_in, T)` を固定する（`C_in = 143 + NB + 128`、B200 は `747`）。
- **Y 帯域**: 係数を 7 ビットとして並べ、MSB の LLR は位相から、残り 6 ビットの LLR は半径の観測値から max-log で生成する（`modem::y_level_llr`）。

### 入力チャンネル 1: 係数の文脈（74 ch）

フレーム `t` の係数 `j`（`0〜63`、帯域 `k = 0〜4`）について。`σ_k` は窓内の**使えるフレーム**における帯域 `k` の係数の RMS（使えるフレームがなければ `1`）。

| チャンネル | 数 | 内容 | 使えるフレーム | 壊れた・欠落 |
|---|---|---|---|---|
| `v[j]` | 64 | `係数 / σ_k` | 復号した値 | `0` |
| `r[k]` | 5 | 誤差分散の対数: `clip(log2(R_k / σ_k²) / 16, −1, 0.5)` | 復号が出す分散 `R_k` | `0.5`（情報なし） |
| `s[0..3]` | 3 | 状態の one-hot（使える / 壊れた / 欠落） | 使える = `1` | 該当する 1 つ |
| `g` | 1 | ヘッダ採用の信頼度: `1 − clip(gap / 8, 0, 1)`（1 位なら `1`） | `gap` から算出 | 壊れた = `1`、欠落 = `0` |
| `c` | 1 | 成分（`M = 0`、`S = 1`） | 定数 | 定数 |

- **高域欠落（高域 CRC のみ不一致）**: 使えるフレームとして扱い、高域（`k >= high_k`、5 帯域プロファイルでは帯域 3・4）の `v` を `0`、`r` を `0.5` とする。

### 入力チャンネル 2: 壊れたフレームの手がかり（69 ch）

届いたが基本 CRC が通らないフレームについて、ヘッダなしで生成できる情報。指数が不明でも仮数は「帯域の最大値に対する比」であるため、帯域内の**相対的な形状や符号**が残る（尺度は文脈から補う）。

| チャンネル | 数 | 内容 |
|---|---|---|
| `h[j]` | 64 | 尺度なしの手がかり: `(E[u] − qmax) / qmax`（`E[u]` は仮数ビットの受信 LLR から求めた期待値、オフセットバイナリ）。`[−1, 1]`。壊れたフレームのみ（他は `0`）。 |
| `q[k]` | 5 | 手がかりの確からしさ: `帯域 k の仮数の事後標準偏差の平均 / qmax` を `clip(·, 0, 1)`。壊れたフレームのみ（他は `0`）。 |

### 入力チャンネル 3: 受信 LLR と刻み（NB + 128 ch）

| チャンネル | 数 | 内容 |
|---|---|---|
| `llr[i]` | `NB`（B200 は 476） | 成分の仮数ビットの受信 LLR（整数）/ 32。欠落フレームは `0` |
| `step[j]` | 64 | 復号したヘッダの刻み: `(log2(刻み / 2^22) + 16) / 16`。不明なフレーム・帯域は `0` |
| `known[j]` | 64 | 刻みが既知かどうか（`1` / `0`） |

### 出力と後処理

出力 `y` の形は `(B, NB + 64, T)`。

- **先頭 `NB`**: 受信 LLR への補正 `[nat]`。
  - 受信 LLR があるビットは `±8 nat`（`CORR_MAX`）に制限（文脈推定で受信の確かなビットを反転させないため）。
  - 受信 LLR がないビット（欠落フレーム）は制限なし。
- **残り 64**: 刻みの特徴（入力 `step` と同尺度）。
  - ヘッダ復号済みフレームは復号した刻みをそのまま使い、不明フレームは出力を満点の `2^-22〜2^-2` に収める（`mendnet.step_of`）。
- **係数と標準偏差の計算**: `E0 = Σ_i P(bit_i = 1) 2^pos_i（オフセット減算）× 刻み` と事後標準偏差（量子化雑音込み）は ONNX グラフ内で計算する（`tools/export_onnx.py`）。帯域分割合成と M/S 逆変換は PostNet のグラフ側で行う。

### 窓のつなぎと演算

- **窓のスライド**: 50 フレームずつずらし、中央 50 フレームだけを確定する（両端 25 フレームは文脈。先頭窓は先頭から、末尾窓は不足分を欠落で埋めて最後まで確定）。確定より後ろの 25 フレームは暫定値として PostNet の先読みに渡す（`restore::Mender`）。
- **演算制約**: ONNX に出せる演算（`Conv1d`, `GELU`, `GroupNorm`, 加算）のみ使用。`GroupNorm` が窓全体で正規化するため、窓長は固定とする。

## 学習データ

- **生成**: `gfm-gen`（`engine/gfm-core/src/dataset.rs`, `tools/gen_mend.py`）が実際の `Decoder`（段 A・A' 込み）を動かし、受信と同じ観測（`restore::Observation`）を書き出す。
- **状態分布**: 人工的な欠落パターンではなく、実際の復号結果から生成する。
- **分割**: 音源の番号で `train` / `val` を分割する（7 本に 1 本が `val`）。

## 損失と評価

- **損失**（`mendnet.bits_loss`）:
  - `ビットの BCE + 0.1 × 刻み (log2) の Huber + 10 × log(1 + 係数の相対誤差)`
  - 使えるフレームと使えないフレームで別々に平均して足し合わせる。
  - 係数の誤差は推定刻みで作った `E0` と原音の差で、二乗和は基底エネルギーで重み付けして波形エネルギーに合わせる。相対誤差の分母は `原音エネルギー + 量子化雑音 + 下限（−80 dBFS/係数、窓全体エネルギーの 1%）`。推定刻みは実範囲（満点の `2^-21〜2^-3`）より広い `2^-22〜2^-2` に収める。
- **評価**（`tools/eval_mendnet.py`）: 使えないフレームの SNR（連続区間長別）、使えるフレームの SNR、AWGN のみの音声（SNR・PSNR・ViSQOL を Es/N0 別）。
- **必須条件**: 実用帯（B200 で Es/N0 16〜30 dB、C/N0 68.4〜82.4 dB-Hz）で「復号のまま」以上であること。聴感を優先する。
