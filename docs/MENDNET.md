# MendNet の設計

MendNet は、全フレームの仮数ビットの LLR と、ヘッダが復号できないフレームの刻みを、前後の文脈・受信 LLR・壊れたフレームに残る手がかりから出す DNN。
使えないフレーム（欠落・基本 CRC 不一致）は補間し、使えるフレームは受信 LLR を補正する。係数は、出力の LLR から求めた仮数の期待値 × 刻み（事後平均 E0）。怪しさは、その事後標準偏差。

網の外れ値は係数の段で抑える（`mendnet.limit_e0`）。欠落フレームの係数と標準偏差は、窓の中の使えるフレームの同じ係数の最大値までに収める。窓より長い欠落（200 ms 超）では窓に手がかりがないので、上限が 0 になって無音になる。ほかのフレームの係数は ±2（満点 1）までに収める。

## 担当

| フレームの状態 | 担当 | 入力 |
|---|---|---|
| 基本 CRC が通る | MendNet（受信 LLR の補正） | 受信 LLR、刻み（ヘッダ）、前後の文脈 |
| 基本 CRC が通らない、届かない | MendNet（補間） | 前後の文脈、受信 LLR、壊れたフレームの尺度なしの手がかり |

CRC が通らないフレームを増やさないために、MendNet の前に、**ヘッダを事前知識つきで復号する段（段 A）** を置く。

受信は 1 系統。

## 段 A: ヘッダの事前知識つき復号（DNN ではない）

ヘッダの情報ビットは予測できる。予測を、ビタビ復号の情報ビット側の軟値に事前分布として足し、基本 CRC を通る確率を上げる。実装済み（`engine/gfm-core/src/prior.rs`）。

| ヘッダの項目 | 予測の源 |
|---|---|
| プロファイル ID、形式識別子、暗号化ビット | 既知（確定値） |
| フレーム番号（16 bit） | 直前に復号できたフレームの番号 + 経過フレーム数 |
| 指数（M/S の各帯域） | 直前に復号できたフレームの指数（近いほど確か） |
| アッテネータ、CRC | 予測しない |

測定（基本 CRC 不一致の割合 [%]）。B200 を直交 Haar で符号化したときの値で、指数の統計は変換で少し変わるので目安:

| 通信路 | なし | 事前知識あり | 上限: 予測できる項目を正解で | 上限: ヘッダ全体を正解で | 上限: ヘッダ + 保護ビットを正解で |
|---|---|---|---|---|---|
| AWGN 5 dB | 79.0 | 47.8 | — | — | — |
| AWGN 6 dB | 46.4 | 21.4 | 16.5 | 0.0 | 0.0 |
| AWGN 7 dB | 16.4 | 7.7 | — | — | — |
| AWGN 8 dB | 3.0 | 1.1 | 0.5 | 0.0 | 0.0 |
| Rayleigh 6 dB | 70.6 | 63.5 | 59.7 | 27.5 | 1.3 |
| Rayleigh 8 dB | 53.2 | 45.4 | 41.9 | 16.6 | 0.9 |

- AWGN: 事前知識は、予測できる項目の上限（16.5%、6 dB）に近い。残りは、予測できないアッテネータと CRC のビット（合わせて 22 bit 程度）による。ヘッダ全体が分かれば、不一致はほぼ 0。保護ビットは AWGN では支配的でない。
- Rayleigh: 深いフェージングでフレーム全体が壊れるため、ヘッダを正解で与えても 16〜28% が残る。保護ビットも分かれば約 1%。

### 段 A': CRC 付きリスト復号

最尤（ビタビ）で基本 CRC が合わなければ、ヘッダを尤度の高い順の候補（リストビタビ）にして、基本 CRC が最初に合うものを採る。実装済み（`framing::unpack` の `list`、既定 8）。

**CRC が合っても、正しい保証はない**。CRC は 12 bit なので、誤った候補が通る確率が 1 候補あたり 2^-12 あり、リストが深いほど増える。通信路の情報が薄いフレームほど、偶然の一致が起きやすい。

測定（上と同じ条件、1000 フレーム）。基本 CRC 不一致 fail [%] / 誤採用 wrong [%]（採用したが、フレーム番号か、基本 CRC が守る指数・アッテネータが真値と違う）。事前知識あり:

| 通信路 | L1 | L4 | **L8** | L16 | L32 |
|---|---|---|---|---|---|
| AWGN 4 dB | 78.5 / 0 | 61.0 / 0 | 53.8 / 0 | 44.5 / 0 | 36.8 / 0.1 |
| AWGN 5 dB | 48.5 / 0 | 27.2 / 0 | 20.5 / 0 | 15.7 / 0 | 11.5 / 0 |
| AWGN 6 dB | 21.7 / 0 | 6.5 / 0 | 4.4 / 0 | 2.3 / 0 | 1.3 / 0 |
| Rayleigh 4 dB | 80.2 / 0 | 75.5 / 0 | 73.8 / 0 | 71.9 / 0.2 | 70.5 / 0.5 |
| Rayleigh 6 dB | 64.2 / 0.1 | 58.3 / 0.1 | 56.2 / 0.1 | 54.2 / 0.2 | 52.3 / 0.4 |
| Rayleigh 8 dB | 46.1 / 0 | 39.9 / 0 | 37.7 / 0.2 | 35.1 / 0.3 | 33.2 / 0.3 |

- 事前知識なしの通常の復号（L1）は、AWGN 5 dB で 78.4%、6 dB で 46.0%。事前知識 + リスト 8 で、20.5% と 4.4%。
- 誤採用は、リストが長いほど増える（L32 で最大 0.5%）。L8 は、AWGN で 0、Rayleigh で最大 0.2%。
- 試して効かなかったもの: 最尤との対数尤度の差（gap）の足切り、通信路がヘッダを支持する強さ（evidence）の足切り（誤採用したフレームの値は、正しいフレームと同じ範囲）、プリアンブルからの雑音分散の校正（AWGN で不一致が増え、誤採用は変わらない）。
- 採用したヘッダの順位（rank）と、最尤との差（gap）は、`Unpacked` に残し、MendNet の信頼度の入力に使う。

## MendNet の入出力

### 単位

窓 1 つ = 成分（M か S）1 つ × T = 100 フレーム（200 ms @ 32 kHz、48 kHz 系も 100 フレーム = 133 ms）。非因果。M と S は別の標本としてバッチ軸に並べ、同じ重みを共有する（S のないプロファイルは M のみ）。送らない帯域と成分の係数は 0 として、形はプロファイルによらず同じ。Y 帯域の係数は 7 ビットとして並べ、最上位ビットの LLR は位相から、残りの 6 ビットの LLR は半径の観測値から max-log で作る（`modem::y_level_llr`）。入力 `x` の形は `(B, C_in, T)`、固定。

### 入力のチャンネル: 係数の文脈（74）

フレーム t の係数 j（0〜63、帯域 k = 0〜4）について。σ_k は、窓の中の**使えるフレーム**の帯域 k の係数の rms（使えるフレームがなければ 1）。

| チャンネル | 数 | 内容 | 使えるフレーム | 壊れた・欠落 |
|---|---|---|---|---|
| `v[j]` | 64 | 係数 / σ_k | 復号した値 | 0 |
| `r[k]` | 5 | 帯域 k の誤差分散の対数: clip(log2(R_k / σ_k²) / 16, −1, 0.5) | 復号が出す分散 R_k | 0.5（情報なし） |
| `s[0..3]` | 3 | 状態の one-hot: 使える / 壊れた（届いたが基本 CRC が通らない）/ 欠落 | 使える = 1 | 該当する 1 つ |
| `g` | 1 | ヘッダの採用の信頼度（1 − clip(gap / 8, 0, 1)。gap は段 A' の最尤との対数尤度の差で、1 位なら 1） | gap | 0 |
| `c` | 1 | 成分（M = 0、S = 1） | 定数 | 定数 |

高域 CRC だけ不一致のフレーム（高域欠落）は、使えるフレームとして扱い、帯域 3、4 の `v` は 0、`r` は 0.5。

### 入力のチャンネル: 壊れたフレームの手がかり（69）

壊れたフレーム（届いたが基本 CRC が通らない）の、ヘッダがなくても作れる情報。

| チャンネル | 数 | 内容 |
|---|---|---|
| `h[j]` | 64 | 尺度なしの手がかり: (E[u] − qmax) / qmax。E[u] は、その係数の仮数ビットの受信 LLR から求めた仮数の期待値（オフセットバイナリ）。[−1, 1]。壊れたフレームだけ。それ以外は 0 |
| `q[k]` | 5 | 手がかりの確からしさ: 帯域 k の仮数の事後標準偏差の平均 / qmax を clip(·, 0, 1) にしたもの。壊れたフレームだけ。それ以外は 0 |

指数が分からなくても、仮数は「帯域の最大値に対する比」なので、帯域内の係数の**相対的な形**（どの係数が大きいか、符号）が残る。尺度は文脈から補う。

### 入力のチャンネル: 受信 LLR と刻み（NB + 128）

| チャンネル | 数 | 内容 |
|---|---|---|
| `llr[i]` | NB（B200 は 476） | 成分の仮数ビットの受信 LLR（整数）/ 32。欠落フレームは 0 |
| `step[j]` | 64 | 復号したヘッダの刻み: (log2(刻み / 2^22) + 16) / 16。分からないフレーム・帯域は 0 |
| `known[j]` | 64 | 刻みが分かるかどうか（1 / 0） |

C_in = 143 + NB + 128（B200 は 747）。

### 出力

`y` の形は `(B, NB + 64, T)`。
- 先頭 NB: 受信 LLR への補正 [nat]。受信 LLR があるビットは ±8 nat（`CORR_MAX`）に収める。文脈から推定して、受信で確かなビットを反転させないため。受信 LLR がないビット（欠落フレーム）は制限なし。
- 残り 64: 刻みの特徴（入力の `step` と同じ尺度）。ヘッダが復号できたフレームは、復号した刻みをそのまま使う。

係数は E0 = Σ_i P(bit_i = 1) 2^pos_i（オフセットを引く）× 刻み、怪しさはその事後標準偏差（量子化の雑音を含む）。どちらも ONNX のグラフの中で出す（`tools/export_onnx.py`）。帯域分割の合成と M/S の逆変換は PostNet のグラフの中。

### 窓のつなぎ

窓を 50 フレームずつずらし、各窓の中央の 50 フレームだけを確定する（両端 25 フレームは文脈）。欠落が窓の端にかかるときは、次の窓で中央に入る。最初の窓は先頭から確定し、ストリームの終わりは最後の窓で残りを確定する（窓に足りなければ欠落で埋める）。窓の残り（確定より後ろの 25 フレーム）は暫定値として PostNet の先読みに渡す（`restore::Mender`）。

### 演算

ONNX に出せるもの（Conv1d、GELU、GroupNorm、足し算）だけ。窓の長さは固定（GroupNorm が窓全体で正規化するため）。

## 学習データ

- gfm-gen（`engine/gfm-core/src/dataset.rs`、`tools/gen_mend.py`）が、実際の Decoder（段 A、A' を含む）を走らせ、受信と同じ観測（`restore::Observation`）を書き出す。
- 状態の分布は、実際の復号の結果から作る。人工の欠落パターンだけにしない。
- train / val は音源の番号で分ける（7 本に 1 本が val）。

## 損失と評価

- 損失（`mendnet.bits_loss`）: ビットの BCE + 0.1 × 刻み（log2）の Huber + 10 × log(1 + 係数の相対誤差)。それぞれ、使えるフレームと使えないフレームで別々に平均して足す。
  係数の誤差は、推定の刻みで作った E0 と原音の差。二乗和は基底のエネルギーで重みを付けて、波形でのエネルギーにする。相対誤差の分母は、原音のエネルギー + 量子化の雑音 + 下限（−80 dBFS / 係数、窓全体のエネルギーの 1%）。推定の刻みは、実際の範囲（満点の 2^-21〜2^-3）より少し広い 2^-22〜2^-2 に収める。
- 評価（`tools/eval_mendnet.py`）: 使えないフレームの SNR を連続区間の長さごとに。使えるフレームの SNR。AWGN のみの音声で SNR・PSNR・ViSQOL を Es/N0 ごとに。
- 必須条件: 実用帯（B200 で Es/N0 16〜30 dB、C/N0 68.4〜82.4 dB-Hz）で、復号のまま以上。
- 聴感を優先する。
